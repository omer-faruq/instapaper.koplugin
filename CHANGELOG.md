# Changelog

## 1.8.0

- Added a filter button to the Unread header. Choose **Hide a tag** or **Show only a tag**, then pick a tag from your Instapaper account. **Turn off** restores the full list.
- The filter requires Instapaper API v2. It persists across restarts and applies only to the Unread browser. **Refresh** remains available in the header menu.
